# America Protective Security Website

A professional security services website built with modern web technologies for optimal performance, accessibility, and user experience.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Modern Stack**: Vanilla JavaScript, Tailwind CSS via CDN
- **Performance Optimized**: Lazy loading, font optimization, efficient caching
- **Accessibility**: WCAG compliant with 7:1 contrast ratios
- **SEO Ready**: Semantic HTML, meta tags, structured data
- **Security Headers**: Comprehensive security configuration for Netlify
- **Professional Aesthetic**: Blue/white/black color palette for government contractor appeal

## 🚀 Deployment

### Netlify Deployment

1. Connect your repository to Netlify
2. Build settings are configured in `netlify.toml`
3. Security headers are defined in `_headers`
4. The site will deploy automatically on push to main branch

### Local Development

1. Clone the repository
2. Open `index.html` in a web browser
3. For live reloading, use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```
